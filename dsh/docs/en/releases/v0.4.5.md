# v0.4.5: Better Sidebar compatibility

[简体中文](../../zh-CN/releases/v0.4.5.md) | **English**

v0.4.5 makes Memory System available inside an installed `dsh-better-sidebar` without replacing its normal DSH Sidebar entry. [Issue #153](https://github.com/omdsh-dev/dsh-mnemon/issues/153), [PR #157](https://github.com/omdsh-dev/dsh-mnemon/pull/157).

## Fixes

- In the default `displayMode: sidebar`, Mnemon now uses Better Sidebar's documented optional `registerTab` service. The single-instance tab has the stable id `dsh-mnemon:memory` and reuses the same Memory System view as the normal DSH Sidebar entry.
- Registration is activation-order independent: Better Sidebar can load before or after Mnemon, and service replacement, unload, or hot reload disposes and restores registration without duplicates.
- A Better Sidebar tab uses the session and workspace scope supplied for that tab rather than leaking the globally active session. Setting `tabEnabled: false` or `displayMode: builtin` continues to suppress this registration.

## Upgrade and compatibility

Install `dsh-mnemon@0.4.5` in the owning DSH profile and restart it. Better Sidebar remains optional and no new runtime dependency is added. The compatibility target tested here is `dsh-better-sidebar@0.18.1-alpha.0`; profiles without that service retain the existing standalone Sidebar behavior.

Memory data, storage paths, Pack formats, Provider credentials, RPC authority, settings, production dependencies, and session projection state are unchanged. No migration or cache deletion is required. The [v0.4.4 session projection compatibility](./v0.4.4.md) remains intact, and this patch contains no unrelated v0.5 development work.

## Verification

The implementation and release candidate passed complete `pnpm run verify` on Node 24.18.0 with pnpm 10.13.1: 649 tests passed and one Windows-only test was skipped on macOS. All 109 deterministic build files, Headless activation with 35 tools and five representative Mnemon tools, settings migration and restart, ten Node-compatible public entries, the 116-file package contents, publint, and attw passed. PR #157 also passed the Linux Node 22.19/24, Windows Node 24, and DSH alpha source CI jobs.

Two isolated real WebUI profiles covered both client activation orders. DSH 0.1.1-rc.2 with `@linxin666/dsh-web-all@0.3.6` loaded Better Sidebar before Mnemon; DSH 0.1.2-alpha.3 loaded Mnemon first. In both cases the normal Sidebar kept exactly one Memory System row, Better Sidebar exposed exactly one menu item, the scoped view rendered, and a fresh browser tab reported zero console errors and zero warnings. Reload restoration also passed in the reported-version profile. See the [environment record and screenshots](../../pr-assets/better-sidebar-153/README.md).

## Rollback

Reinstall `dsh-mnemon@0.4.4` in the same profile and restart it. No data conversion is needed. Better Sidebar can retain an already opened `dsh-mnemon:memory` tab in its own persisted layout; after rollback that tab can temporarily appear orphaned and may be closed. The normal DSH Sidebar entry remains available.
