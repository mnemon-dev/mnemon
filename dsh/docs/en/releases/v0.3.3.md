# v0.3.3: Correct Checkpoint Subagent Usage

[简体中文](../../zh-CN/releases/v0.3.3.md) | **English** | [Capability map](../guides/capabilities.md)

v0.3.3 is a focused WebUI correctness patch for checkpoint-started subagents. Their catalog rows now report only the provider usage incurred by that child instead of adding the completed parent history inherited by the fork.

## Fixed

- Fork-backed subagents inherit the parent's durable event prefix, while DSH's generic `tokenUsage` projection intentionally totals the complete log. The official subagent dropdown previously treated that aggregate as child-run usage, so a parent using 8.7K tokens and a child using 7K appeared as 15.7K for the child. Mnemon now owns a descriptor-scoped projection that starts at the latest durable `subagent/descriptor`, replaces repeated usage samples from the same turn and step, and exposes the resulting value only to the official subagent catalog component. This was delivered through [PR #87](https://github.com/omdsh-dev/dsh-mnemon/pull/87).
- The compatibility adapter falls back to the official aggregate for legacy child sessions without a durable descriptor. DSH's kernel, checkpoint and fork behavior, generic complete-log `tokenUsage`, official UI source, navigation, locale, and styling remain unchanged.

## Documentation

- The English and Chinese README headers now include the live dshfind download count alongside the existing package and repository badges, delivered through [PR #82](https://github.com/omdsh-dev/dsh-mnemon/pull/82).

## Compatibility and upgrade

No Runtime, Document, Memory Space, Provider, configuration, RPC, tool, or persistence format changes require migration. The scoped projection is optional when the DSH projection service is absent, and the client adapter remains inert when the official subagent lineage slot is unavailable.

Update `dsh-mnemon`, restart each DSH profile that uses it, and reopen the affected parent conversation. Existing session logs do not need rewriting; their scoped value is folded from the durable descriptor on read. Rollback to `0.3.2` requires no data rollback, but the dropdown will again show the inherited complete-log aggregate for checkpoint children.
