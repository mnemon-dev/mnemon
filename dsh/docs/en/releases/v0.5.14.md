# v0.5.14: Desktop Loading, OpenViking User Keys and Agent Teams Review

[简体中文](../../zh-CN/releases/v0.5.14.md) | **English**

v0.5.14 includes three fixes:

- [#277](https://github.com/omdsh-dev/dsh-mnemon/pull/277) fixes [#274](https://github.com/omdsh-dev/dsh-mnemon/issues/274): profile bundles load on older Desktop hosts whose Cosmokit does not provide the Volatile APIs. Live settings remain available on newer hosts; Starter groups, component switches and existing settings namespaces are preserved.
- [#276](https://github.com/omdsh-dev/dsh-mnemon/pull/276) fixes [#271](https://github.com/omdsh-dev/dsh-mnemon/issues/271): OpenViking user-bound API keys can discover their own memory namespace without Admin access. Set the account and **User key owner (skip admin)** explicitly. Discovery validates the scoped data API before saving; an invalid replacement preserves the prior configuration and credentials. Default Admin discovery remains available.
- [#278](https://github.com/omdsh-dev/dsh-mnemon/pull/278) fixes [#275](https://github.com/omdsh-dev/dsh-mnemon/issues/275): an explicit scoped mode enables idle review with the verified DSH and official Agent Teams 0.1.7-rc.1 combination. The reviewer retains complete live-user decisions in its bounded checkpoint and can use only its authorized memory tools. Team delegation stays denied inside the reviewer, while the parent Team continues to work.

## Packages and upgrade

| Package | Previous | New |

The other fourteen companion packages retain their versions. The Starter pins the complete tested combination. Mnemon CLI remains independently maintained; the local verification uses the official CLI 0.2.9.

Back up the DSH profile configuration and relevant Mnemon data, then upgrade:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.14
```

Restart DSH and reload the browser. Substitute `headless` for that Profile. The Client floor remains DSH 0.1.5-rc.1; the complete DSH profile requires Node `^22.19.0 || >=24.0.0`.

## Agent Teams compatibility and data

**The default remains `idleReview.agentTeams: pause`.** Select `scoped` explicitly after using the verified DSH/Teams 0.1.7-rc.1 combination. Older DSH 0.1.5-rc.2 with Teams 0.1.5-alpha.2 can reject the reviewer with `TEAM_NOT_MEMBER`; this release does not automatically enable scoped review on that combination or bypass another plugin's policy.

Runtime, Documents and Memory Spaces storage formats are unchanged. Profile ownership, revision checks and multi-plugin isolation remain in place. A downgrade restores the prior behavior and requires reconciliation of the new optional settings with the backed-up profile; no reverse migration is added.
