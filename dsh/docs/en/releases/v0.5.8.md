## Runtime archival

Archive destinations must support exact synchronous writes and safe deletion before any write starts. The Host rechecks every destination and current Runtime revision, retains per-destination receipts, and compensates only entries proven to have been newly created. Deduplicated or updated records are preserved, and an uncertain local commit does not trigger deletion of the archived copy.

Invalid routing proposals fall back as a whole batch to the validated default destination. Earlier valid batches and complete original content are retained. A destination disabled during routing is rejected before Provider writes or Runtime changes. A Provider that performs a partial remote write and then throws without reporting a receipt still cannot offer a cross-storage rollback guarantee.

## Delegated review and WebUI

- Keep the delegated result tool name and schema stable throughout the Host lifetime. Revocable per-run requests enforce child ownership, result validation, cancellation, concurrent isolation and disposal.
- Reuse complete inherited review evidence. A child execution guard also covers tools registered directly by other plugins and Code Mode subcalls; bounded Document search remains available when evidence is incomplete.
- Show idle-review failures in the Memory system workspace and Host log. Warnings survive ordinary turns until review succeeds or the session resets; context-window failures include actionable guidance.
- Keep the Mnemon sidebar entry visible and clickable under the ORCA LINK skin, including its collapsed layout.

Tool-definition stability is verified; this release does not claim measured model cache hits, token savings or cost reductions.

## Packages and upgrade

Only the `dsh-mnemon` Starter advances, from `0.5.7` to `0.5.8`, on npm's `latest` channel. All sixteen independently versioned plugins retain their tested versions: the Runtime, Documents and Memory Spaces Sources remain at `0.5.6`; Mnemon Native Provider and Default Three-tier Strategy remain at `0.5.5`; the other eleven remain at `0.5.4`. Mnemon CLI continues to be maintained separately.

```sh
dsh plugin --profile web add dsh-mnemon@0.5.8
```

Restart DSH and reload the browser. Use `headless` for that Profile. The full DSH profile requires Node `^22.19.0 || >=24.0.0`. Existing storage formats and supported DSH peer ranges are preserved.
