# v0.5.16: Chinese Metadata, Native Sidebar and Source Scrolling

[简体中文](../../zh-CN/releases/v0.5.16.md) | **English**

v0.5.16 includes three UI and packaging fixes:

- [#286](https://github.com/omdsh-dev/dsh-mnemon/pull/286) adds a Chinese display name and description for the root plugin in DSH, with the existing English manifest fallback. Locale resources are checked in packed artifacts, and locale-only changes now participate in release validation. The contributor's original commit [`d16d017`](https://github.com/omdsh-dev/dsh-mnemon/commit/d16d017aa5bb0c3bbbdb40dc5a95554266b6522a) is preserved, with validation and release maintenance appended.
- [#287](https://github.com/omdsh-dev/dsh-mnemon/pull/287) moves Memory System into DSH's native Sidebar and main panel. Switching to Plugins reveals the selected page; returning preserves Source state. Native row styling, collapsed navigation and header visibility work with the tested official theme and Maid Atelier skin. Better Sidebar and replacement-layout fallbacks remain supported.
- [#288](https://github.com/omdsh-dev/dsh-mnemon/pull/288) aligns Runtime, Documents and Memory Spaces with the Status page's insets and scroll container. Memory Spaces keeps its title and tabs together while scrolling. Tab changes reset only the owning canvas; opening Related places its heading and close button below the fixed header.

## Packages and upgrade

| Package | Previous | New |
|---|---|---|
| `dsh-mnemon` | 0.5.15 | **0.5.16** |
| `dsh-mnemon-source-memory-spaces` | 0.5.9 | **0.5.10** |

The other fifteen companion packages retain their versions. Upgrade Root and Memory Spaces Source together for the complete fix; the Starter pins the full seventeen-package combination. Mnemon CLI remains independently maintained.

Back up the DSH profile configuration and relevant Mnemon data, then upgrade:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.16
```

Restart DSH and reload the browser. Substitute `headless` for that Profile. The Client floor remains DSH 0.1.5-rc.1; complete profiles require Node `^22.19.0 || >=24.0.0`.

## Compatibility and data

No persistence migration is required. Stored memory, storage formats and Provider permissions are unchanged. The Source callbacks `onResetScroll` and `onRevealElement` are optional, retaining compatibility with older Hosts; those Hosts require manual scrolling. The existing Root peer floor is unchanged.

Published DSH 0.1.7-rc.2 still displays the `cordis:group` container as Off while its children run, and its displayed switch can return `unknown-plugin`. This release does not patch DSH or install a replacement plugin-management adapter. The local upstream candidate retained in the evidence is separate from the shipped Mnemon runtime.
