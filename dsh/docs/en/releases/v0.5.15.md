# v0.5.15: USER Tool Writes, Runtime Metadata and Skin Hooks

[简体中文](../../zh-CN/releases/v0.5.15.md) | **English**

v0.5.15 includes these improvements:

- [#282](https://github.com/omdsh-dev/dsh-mnemon/pull/282) fixes [#281](https://github.com/omdsh-dev/dsh-mnemon/issues/281): `mnemon_runtime_memory` accepts the empty `branches: []` placeholder supplied by model tool layers for `target=user`, restoring USER add, replace and remove operations. Non-empty USER branches remain rejected; MEMORY branch assignment and clearing are unchanged.
- [#283](https://github.com/omdsh-dev/dsh-mnemon/pull/283) resolves [#280](https://github.com/omdsh-dev/dsh-mnemon/issues/280): Runtime model-context projections include stored importance and creation/update ages in days. Default Strategy guidance explicitly acknowledges the context budget: an absent entry does not mean it was deleted.
- [#284](https://github.com/omdsh-dev/dsh-mnemon/pull/284) implements [#273](https://github.com/omdsh-dev/dsh-mnemon/issues/273): Sidebar and Builtin expose a stable Mnemon root selector supporting `--mn-bg`, `--mn-backdrop` and `--mn-surface` overrides. The [skin development guide](../development/skin-integration.md) covers dsh-web integration, migration from generated class names and verification.

The other fourteen companion packages retain their versions. The Starter pins the complete combination. Mnemon CLI remains independently maintained; local verification of the fixes uses the official CLI 0.2.9.

Back up the DSH profile configuration and relevant Mnemon data, then upgrade:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.15
```

Restart DSH and reload the browser. Substitute `headless` for that Profile. The Client floor remains DSH 0.1.5-rc.1; the complete DSH profile requires Node `^22.19.0 || >=24.0.0`.

## Compatibility and data

Original Runtime content, JSON/Markdown storage formats, exact matching and capacity accounting are unchanged. The Source generates the added metadata when compiling model projections; no data migration is needed. Each turn still uses a fixed snapshot, and Scoped, Light Context and Auto Capture remain composable.

The official theme retains its default opaque background. Existing skins must explicitly use the public selector and properties to customize Mnemon backgrounds; installing a skin does not automatically enable a glass effect. Dialogs portaled to `body` keep their own styles. Skin integration does not change Provider or data permissions.
