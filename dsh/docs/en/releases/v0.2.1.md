# v0.2.1: Literal Braces in Runtime Memory

[简体中文](../../zh-CN/releases/v0.2.1.md) | **English** | [Capability map](../guides/capabilities.md)

v0.2.1 is a focused patch release for system-prompt assembly. Runtime Memory can now contain the exact literal text `{{}}` without causing the entire turn to fail.

## Fixed

- Exact literal `{{}}` text in `USER.md` or `MEMORY.md` is preserved in the assembled `mnemon:runtime-memory` section.
- Valid prompt variables in the same memory text continue to interpolate normally.
- Prompt variables and behavior in every other system-prompt section remain unchanged.

The fix routes only the empty-brace literal through a dedicated Mnemon prompt variable. The host interpolator does not rescan substituted values, so the model receives the original `{{}}` text without weakening strict validation for real prompt-variable references.

## Documentation

The repository landing page now features the live multi-memory graph snapshot with clearer descriptions of observable Provider surfaces.

## Upgrading

Update dsh-mnemon and restart the affected DSH profile. This patch does not migrate, rewrite, or delete Runtime Memory, Project Documents, Memory Spaces, or Provider data.

See the [v0.2.0 release notes](./v0.2.0.md) for the complete three-tier memory system introduced in the current minor release.
