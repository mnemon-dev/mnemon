# v0.3.1: Entity Explorer and Sidebar Polish

[简体中文](../../zh-CN/releases/v0.3.1.md) | **English** | [Capability map](../guides/capabilities.md)

v0.3.1 is a focused Web UI patch for the v0.3 composable-memory line. It makes large entity collections faster to inspect, keeps long entity names inside their rail rows, aligns the Memory System entry with sibling sidebar plugins, and replaces fixed README badges with live public project indicators.

## Updated

- The Entity explorer now filters its already-loaded top-entity rail as the user types. Matching is locale-aware, case-insensitive, and local: typing does not add an RPC or Provider request, the existing **Inspect** submission remains unchanged, and Escape clears only the live filter.
- Long entity names stay on one truncated line while their frequency counts remain pinned inside the right edge of each row. Sidebar pagination and visible-result totals use the filtered collection.
- The Memory System sidebar entry now uses the same 36px row geometry, 18px glyph, fixed 24px icon box, spacing, active colors, and collapsed circular rail treatment as the current SSH and Task Board entries.
- The English and Chinese README headers now expose live npm version and download counts, the latest GitHub release, stars, license, and the matching dshfind badge instead of fixed product counters.

Thanks to [@kiligzzz](https://github.com/kiligzzz) for the entity-rail fixes and live filter in [PR #72](https://github.com/omdsh-dev/dsh-mnemon/pull/72) and [PR #73](https://github.com/omdsh-dev/dsh-mnemon/pull/73), and to [@ch3n4y](https://github.com/ch3n4y) for the sidebar-entry alignment in [PR #76](https://github.com/omdsh-dev/dsh-mnemon/pull/76).

## Compatibility and upgrade

This patch changes Client UI behavior, CSS, tests, screenshots, and README presentation only. Host behavior, the composable memory kernel, configuration keys, RPC authority, public tool schemas, persistence formats, Providers, credentials, and existing Runtime, Document, and Memory Space data are unchanged.

No data migration is required. Update `dsh-mnemon`, restart each DSH profile that uses it, and reopen the Memory System surface. Package rollback to `0.3.0` requires no reverse migration.
