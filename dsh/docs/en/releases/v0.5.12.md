# v0.5.12: DSH RC and Alpha Compatibility

[简体中文](../../zh-CN/releases/v0.5.12.md) | **English**

v0.5.12 includes [#263](https://github.com/omdsh-dev/dsh-mnemon/pull/263), fixing [#261](https://github.com/omdsh-dev/dsh-mnemon/issues/261). The turn memory bar registers with a stable ID required by DSH 0.1.6-alpha.2's list slot while retaining the 0.1.5-rc.2 chain selector. Activity is read and displayed only for completed turns. The save-to-memory action also mounts correctly after registration succeeds.

Sidebar and Settings now follow DSH's public default/main session binding. Builtin and Better Sidebar retain their explicitly owning session, including an absent session, so switching workspaces does not borrow another session's memory scope.

## Packages and upgrade

Only **`dsh-mnemon` 0.5.12** is newly published. All sixteen companion plugins retain their versions and exact Starter pins. No configuration or stored-memory migration is required; Mnemon CLI remains independently maintained.

The Client compatibility floor is now **DSH 0.1.5-rc.1**. Both root framework peers declare `^0.1.5-rc.1 || ^0.1.6-alpha.2`; 0.1.5-rc.2 and 0.1.6-alpha.2 were explicitly verified. Older DSH hosts without the public UI Session service must use their previously verified Mnemon release.

```sh
dsh plugin --profile web add dsh-mnemon@0.5.12
```

Restart DSH and reload the browser. Substitute `headless` for that Profile. The full DSH profile requires Node `^22.19.0 || >=24.0.0`.

## Verification

Both tested DSH cohorts passed full production public type checks, normal packed npm installation, real WebUI tool calls, Sidebar/Builtin navigation, turn-bar toggles and page reload. Alpha additionally verified two independent peer slot contributions and memory isolation when switching workspaces. Packed Headless runs checked seventeen Mnemon tools, actual Runtime writes/status, persistence across a new process and zero tools after disabling Root.

The implementation passed 1,183 root tests with five opt-in live Flash skips, actual Mnemon Native CLI 0.2.8 integration, and sixteen-plugin/seventeen-artifact composition and upgrade checks. Live OpenViking and Windows-only checks were skipped in the macOS run. The [bilingual evidence report](../../pr-assets/issue-261-dsh-slots/README.md) retains original before/after screenshots, artifact integrity and reproducible scripts. Its model responses use an explicit local OpenAI/Anthropic fixture; it makes no live-model quality claim.

The release workflow revalidates the versioned artifacts, installs the full pinned Registry composition, publishes the Starter, and checks a real upgrade from v0.4.7 before creating the GitHub Release.
