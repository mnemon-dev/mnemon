# v0.5.11: Quiet Windows Git Branch Detection

[简体中文](../../zh-CN/releases/v0.5.11.md) | **English**

v0.5.11 includes [#260](https://github.com/omdsh-dev/dsh-mnemon/pull/260), fixing [#259](https://github.com/omdsh-dev/dsh-mnemon/issues/259). Runtime Git branch detection now hides its Windows console, preventing brief terminal windows when a GUI host refreshes branch-scoped memory. The Git command, two-second timeout, branch filtering and failure fallback are unchanged.

## Packages and upgrade

| Package | Version |
| --- | --- |
| `dsh-mnemon` | **0.5.11** |
| `dsh-mnemon-source-runtime` | **0.5.8** |

The Starter pins the complete sixteen-plugin composition. The other fifteen plugins retain their versions. No configuration or stored-memory migration is needed; Mnemon CLI remains independently maintained.

```sh
dsh plugin --profile web add dsh-mnemon@0.5.11
```

Restart DSH and reload the browser. Substitute `headless` for that Profile. The full DSH profile requires Node `^22.19.0 || >=24.0.0`.

## Verification

Four real Windows process trials observed 104–105 visible console windows per baseline trial and zero after the fix. Each trial made 104 real Git calls and verified branch results and fallback behavior from a console-free parent. The new regression failed before the fix; all 59 Runtime tests pass afterward.

The implementation passed 1,162 root tests with five opt-in skips, actual Mnemon CLI 0.2.8 checks, real macOS WebUI operations, Headless startup/restart and sixteen-plugin/seventeen-artifact composition checks. All three optional Strategies were enabled together. The [bilingual evidence report](../../pr-assets/issue-259-windows-git-console/README.md) retains tested revisions, before/after screenshots and downloadable Windows observations. It distinguishes Windows process validation from macOS WebUI checks and does not claim a complete replay of the reporter's Windows 11 Electron environment.

The release workflow verifies versioned artifacts, publishes Runtime before the Starter, checks the full Registry composition and a real upgrade from v0.4.7, then creates the GitHub Release.
