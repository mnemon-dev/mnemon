## Real WebUI

The existing [packed Team fixture](../../../scripts/fixtures/serve-team-review.mjs) ran all seventeen release-version tarballs on an isolated official DSH/Teams 0.1.7-rc.1 Profile with the official CLI and all three Strategy enhancements enabled. The fixture uses disposable storage and a loopback model endpoint; no external model API was used.

1. Opened Memory System and observed `dsh-mnemon 0.5.14` with healthy status.
2. Added a synthetic Runtime entry through the UI, then edited it and observed the exact saved content.
3. Changed Agent Teams from the default `pause` to `scoped` through Settings and observed the saved/live status.
4. Stopped and restarted the Host process through the fixture's `SIGUSR2` cold-restart handler, then reopened the authenticated UI. Runtime content remained visible and its file SHA-256 was byte-identical. Settings still selected `scoped`, and all three Strategy enhancement checkboxes remained enabled.
