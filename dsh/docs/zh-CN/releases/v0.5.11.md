# v0.5.11：隐藏 Windows Git 分支查询窗口

**简体中文** | [English](../../en/releases/v0.5.11.md)

v0.5.11 包含 [#260](https://github.com/omdsh-dev/dsh-mnemon/pull/260)，修复 [#259](https://github.com/omdsh-dev/dsh-mnemon/issues/259)。Runtime 查询 Git 分支时会隐藏 Windows 控制台，避免 GUI 宿主刷新分支记忆时短暂弹出终端窗口。Git 命令、两秒超时、分支过滤与失败回退均保持不变。

## 发布包与升级

| 包 | 版本 |
| --- | --- |
| `dsh-mnemon` | **0.5.11** |
| `dsh-mnemon-source-runtime` | **0.5.8** |

Starter 精确固定完整的十六插件组合，其余十五个插件保持原版本。无需迁移配置或已有记忆；Mnemon CLI 继续独立维护。

```sh
dsh plugin --profile web add dsh-mnemon@0.5.11
```

重启 DSH 并刷新浏览器；Headless Profile 将命令中的 `web` 替换为 `headless`。完整 DSH Profile 需要 Node `^22.19.0 || >=24.0.0`。

## 验证

四轮真实 Windows 进程测试中，原版每轮出现 104–105 个可见控制台窗口，修复后均为零。每轮从已确认无控制台的父进程执行 104 次真实 Git 调用，并验证分支结果与失败回退。新增回归测试在修复前失败，修复后全部 59 项 Runtime 测试通过。

实现通过 1,162 项根包测试，5 项 opt-in 跳过，并完成真实 Mnemon CLI 0.2.8、macOS WebUI 操作、Headless 启动与重启，以及十六个插件、十七个制品的组合验证。三个可选 Strategy 同时启用。[双语证据报告](../../pr-assets/issue-259-windows-git-console/README.zh-CN.md)保留验证版本、前后截图与可下载 Windows 观测数据，明确区分 Windows 进程验证和 macOS WebUI 检查，不声称已完整重放报告者的 Windows 11 Electron 环境。

发布流程验证版本化制品，先发布 Runtime，再发布 Starter；完整 Registry 组合和从 v0.4.7 开始的真实升级检查通过后，才创建 GitHub Release。
