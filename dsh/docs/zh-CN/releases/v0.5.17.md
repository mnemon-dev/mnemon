# v0.5.17：可组合策略与组件设置

**简体中文** | [English](../../en/releases/v0.5.17.md)

v0.5.17 包含 v0.5.16 后合入的十三个 PR。Starter 现在精确固定十八个包，其中包括新增的通用策略。

- **策略与记忆组合**（[#294](https://github.com/omdsh-dev/dsh-mnemon/pull/294)、[#299](https://github.com/omdsh-dev/dsh-mnemon/pull/299)、[#301](https://github.com/omdsh-dev/dsh-mnemon/pull/301)）：在插件页选择分层策略或通用策略，依据组件声明组合 Source 与增强，并联动处理依赖开关。通用策略接入可用 Source，由模型决定如何使用；标准 selection、projection、capture 增强可以跟随任一主策略。没有主策略运行时，对话可不带记忆继续。
- **组件设置与界面**（[#297](https://github.com/omdsh-dev/dsh-mnemon/pull/297)、[#298](https://github.com/omdsh-dev/dsh-mnemon/pull/298)、[#300](https://github.com/omdsh-dev/dsh-mnemon/pull/300)、[#302](https://github.com/omdsh-dev/dsh-mnemon/pull/302)）：在 DSH 插件页配置 Mnemon，每个组件拥有自己的设置页，并可提供状态卡片。开关和选择器立即生效，输入值通过“应用”保存。数据目录明确区分“默认”和“自定义”。界面采用 DSH 原生控件和主题令牌。
- **可选 CLI 与平等的 Provider**（[#295](https://github.com/omdsh-dev/dsh-mnemon/pull/295)）：仅 Mnemon Native 需要 Mnemon CLI。Native 不可用时，其他已就绪的 Provider 可继续提供记忆空间；已保存的 Provider 选择仍然生效。
- **命名与导航**（[#290](https://github.com/omdsh-dev/dsh-mnemon/pull/290)、[#292](https://github.com/omdsh-dev/dsh-mnemon/pull/292)、[#303](https://github.com/omdsh-dev/dsh-mnemon/pull/303)）：保留“可组合记忆 (dsh-mnemon)”，将分层记忆描述为默认组合，侧栏使用细线大脑图标。Git 忽略本地凭据和工具状态。
- **宿主兼容与说明**（[#293](https://github.com/omdsh-dev/dsh-mnemon/pull/293)、[#291](https://github.com/omdsh-dev/dsh-mnemon/pull/291)）：以正式发布的 DSH 0.1.7-rc.2 契约为基线，移除旧宿主兼容路径，并说明上游 `cordis:group` 显示问题。

- **通用策略读取回执**：发布验收发现 Source 证据缺少可选 `score` 或 `revision` 时，DSH 会拒绝工具返回值。Host 现在为 `mnemon_recall` 和 `mnemon_related` 保留字段的缺省语义，同时保留零分数及已有修订值。

## 升级与兼容

**本版支持 DSH 0.1.7-rc.2。更早的宿主请继续使用 v0.5.16。** 完整 Profile 需要 Node `^22.19.0 || >=24.0.0`；包的 Node 入口导入下限仍为 20。

备份 Profile 配置和记忆数据后，安装完整 Starter：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.17
```

升级后重启 DSH 并刷新浏览器；Headless Profile 将命令中的 `web` 替换为 `headless`。Mnemon CLI 独立维护版本，仅使用 Mnemon Native 时需要。

记忆存储格式不变。DSH 插件管理器可用时，旧组件选择会迁移到 Profile patch。修改数据目录不会搬移已有记忆，更换位置时需要显式复制或恢复数据。回滚时除数据备份外，也应保留 Profile 配置备份。

五个策略包使用本次新增的标准 View 扩展 SDK，因此将 `dsh-mnemon` peer 下限提高到 `^0.5.17`。请整体升级 Starter 固定的组合；独立安装插件时也必须满足该依赖下限。

DSH 0.1.7-rc.2 仍可能将运行中组件的 `cordis:group` 容器显示为关闭，点击该容器开关可能返回 `unknown-plugin`。本版不修改 DSH，参见[兼容性说明](../reference/compatibility.md#dsh-017-bundle-组件列表)与[上游 issue #649](https://github.com/dsh-external/issues/issues/649)。
