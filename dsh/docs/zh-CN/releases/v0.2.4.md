# v0.2.4：受信远程设置

**简体中文** | [English](../../en/releases/v0.2.4.md) | [能力地图](../guides/capabilities.md)

v0.2.4 补齐了 v0.2.3 引入的受信远程管理链路，并修复「设置 → 记忆系统」空白页。

## 修复

- 以 Host 返回的可写 settings snapshot 作为浏览器管理能力的权威信号；不再仅因连接非 loopback 就将其判定为只读。
- Provider 服务设置与 Mnemon Pack 控件使用同一组经 Host 授权的管理通道。
- 两个设置命名空间都不可用时，页面会显示可操作的授权诊断，不再返回空内容。

## 安全边界

- `remoteAccess` 仍默认为 `read-only`，且不能通过 Web 设置修改。
- 显式设置 `remoteAccess: trusted-host` 时，Host 会在启动时一起提升 `/dsh-mnemon-write`、`/dsh-mnemon-settings` 和 `/dsh-mnemon-pack`。
- 部署还必须为远程页面提供身份验证，配置 DSH Connection `trustedHosts` 白名单，保持同源，并重启 Host。不要在未认证的公网端点开启远程管理。

## 升级

更新 dsh-mnemon 后重启对应 DSH profile。本补丁不会迁移、改写或删除运行时记忆、项目档案、记忆空间、Provider 数据或已保存凭据。

上一个已发布补丁版本见 [v0.2.2 发布说明](./v0.2.2.md)。
