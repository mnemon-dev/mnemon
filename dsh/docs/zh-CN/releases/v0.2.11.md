# v0.2.11：响应式且可靠的弹窗交互

**简体中文** | [English](../../en/releases/v0.2.11.md) | [能力地图](../guides/capabilities.md)

v0.2.11 是一次聚焦用户界面的补丁发布，确保 Mnemon 弹窗在手机、窄侧栏和矮横屏视口中保持可用。

## 改进

- Mnemon 工作区弹窗现在统一采用固定页眉、独立滚动正文和固定操作区。创建、编辑、元数据维护、沉淀策略、沉淀记忆、运行时记忆、项目档案、版本检查、全文预览及危险操作确认均无需滚动整个弹窗即可操作。
- 窄视口中的工作区弹窗以适配安全区的底部 Sheet 呈现；动态视口单位、横屏边距、滚动边界和 44px 触控目标覆盖手机与粗指针平板设备。
- 危险操作确认会固定显示取消与确认按钮，较长的记忆内容、路径或档案摘要在正文区域内独立滚动。
- 对话中的“保存到记忆”弹窗现在会受移动端和矮视口边界约束，同时保留 DSH 宿主原生外观。

## 无障碍与可靠性

- 共享工作区弹窗现在会约束键盘焦点、选择安全的初始控件、关闭后将焦点归还触发入口，并在异步内容就绪后把焦点移交给相关操作。
- 只读加载期间仍可关闭版本检查；关闭时会使未完成请求失效，延迟返回的结果不会重新打开或更新已关闭弹窗。
- 全文预览现在使用共享响应式弹窗契约，包含可访问标题与描述、焦点约束和归还、安全区处理以及适合触控的关闭按钮。
- 写入操作繁忙时仍会阻止关闭和重复提交，只读加载不再被误判为不可中断的变更。

## 安全与兼容性

- 存储格式、Provider 连接、配置键、RPC 权限、公开工具 schema 和服务端行为均未改变，已有数据无需迁移。
- 更新 dsh-mnemon 并重启受影响的 DSH profile 即可；如需回滚，正常降级包版本即可恢复此前的客户端呈现。

## 验证

- 本地完整测试套件共 38 个文件、358 项测试通过；Windows 专用 smoke test 只会在非 Windows 本地环境跳过。
- 定向交互覆盖焦点进入与归还、焦点圈定、异步焦点迁移、关闭守卫、延迟响应丢弃、固定操作区、安全区、动态视口尺寸和触控目标。
- 已在隔离的 DSH WebUI 中检查全部 16 个弹窗交互；版本流程包含加载态和结果态，因此共捕获 17 个移动端状态，并补充竖屏、窄屏和矮横屏前后对比。
- 类型检查、确定性构建、Headless 激活、发布包校验、publint、attw，以及 Ubuntu 与 Windows CI 均通过。
