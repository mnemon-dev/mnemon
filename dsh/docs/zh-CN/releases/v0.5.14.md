# v0.5.14：Desktop 加载、OpenViking User Key 与 Agent Teams 审查

**简体中文** | [English](../../en/releases/v0.5.14.md)

v0.5.14 包含三项修复：

- [#277](https://github.com/omdsh-dev/dsh-mnemon/pull/277) 修复 [#274](https://github.com/omdsh-dev/dsh-mnemon/issues/274)：旧版 Desktop 宿主的 Cosmokit 不提供 Volatile API 时，Profile bundle 仍可正常加载。新版宿主继续使用实时设置，保留 Starter 分组、组件开关与已有设置命名空间。
- [#276](https://github.com/omdsh-dev/dsh-mnemon/pull/276) 修复 [#271](https://github.com/omdsh-dev/dsh-mnemon/issues/271)：OpenViking 绑定用户的 API Key 无需 Admin 权限即可发现自身记忆命名空间。请显式填写账户和 **User Key 所属用户（跳过 Admin）**；发现流程先校验限定范围的数据 API，再保存。替换配置被拒绝时，原有配置与凭据保留；默认 Admin 发现方式仍可使用。
- [#278](https://github.com/omdsh-dev/dsh-mnemon/pull/278) 修复 [#275](https://github.com/omdsh-dev/dsh-mnemon/issues/275)：新增显式受限模式，让空闲审查在已验证的 DSH 与官方 Agent Teams 0.1.7-rc.1 组合中运行。审查器在有界检查点内保留完整的真实用户决定，只能使用授权范围内的记忆工具；审查器内部仍禁止 Team 委派，父级 Team 可以继续工作。

## 包版本与升级

| 包 | 原版本 | 新版本 |
|---|---|---|
| `dsh-mnemon` | 0.5.13 | **0.5.14** |
| `dsh-mnemon-provider-openviking` | 0.5.5 | **0.5.6** |
| `dsh-mnemon-source-memory-spaces` | 0.5.8 | **0.5.9** |

其余十四个配套包版本不变，Starter 精确固定经过验证的完整组合。Mnemon CLI 仍独立维护，本地验证使用官方 CLI 0.2.9。

备份 DSH Profile 配置及相关 Mnemon 数据，然后升级：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.14
```

重启 DSH 并刷新浏览器。Headless Profile 将命令中的 `web` 换为 `headless`。Client 下限仍为 DSH 0.1.5-rc.1，完整 DSH Profile 要求 Node `^22.19.0 || >=24.0.0`。

## Agent Teams 兼容性与数据

**默认仍为 `idleReview.agentTeams: pause`。** 使用已验证的 DSH/Teams 0.1.7-rc.1 组合后，手动选择 `scoped`。旧版 DSH 0.1.5-rc.2 与 Teams 0.1.5-alpha.2 仍可能以 `TEAM_NOT_MEMBER` 拒绝审查器；本版不会在该组合上自动开启受限审查，也不会绕过其他插件的策略。

Runtime、Documents 与 Memory Spaces 存储格式不变，保留 Profile 所有权、修订检查和多插件隔离。降级会恢复旧版行为，需要结合备份的 Profile 核对新增可选设置；本版没有增加逆向迁移。
