# v0.3.1：实体查阅与侧边栏体验修整

**简体中文** | [English](../../en/releases/v0.3.1.md) | [能力地图](../guides/capabilities.md)

v0.3.1 是 v0.3 可组合记忆版本线的一次聚焦 Web UI 补丁：大型实体集合可以更快查阅，长实体名不会再挤出行内频次，记忆系统入口与兄弟侧边栏插件对齐，同时 README 的固定徽章更新为实时公开项目指标。

## 更新内容

- 实体查阅页会随着输入实时筛选已加载的高频实体列表。匹配采用本地、忽略大小写且适配 locale 的包含判断；输入过程不会新增 RPC 或 Provider 请求，原有“查阅”提交行为保持不变，Escape 只清除实时筛选。
- 长实体名保持单行省略，频次固定在每一行的右侧边界内；Sidebar 分页和可见结果总数使用筛选后的集合。
- 记忆系统侧边栏入口与当前 SSH、任务板入口统一为 36px 行几何、18px 图标、固定 24px 图标盒、相同间距与激活颜色，并在折叠栏中使用一致的圆形按钮形态。
- 中英文 README 顶部改为展示实时 npm 版本与总下载量、最新 GitHub Release、Star、许可证和对应语言的 dshfind 徽章，不再维护固定产品计数。

感谢 [@kiligzzz](https://github.com/kiligzzz) 在 [PR #72](https://github.com/omdsh-dev/dsh-mnemon/pull/72) 与 [PR #73](https://github.com/omdsh-dev/dsh-mnemon/pull/73) 中完成实体列表修复和实时筛选，也感谢 [@ch3n4y](https://github.com/ch3n4y) 在 [PR #76](https://github.com/omdsh-dev/dsh-mnemon/pull/76) 中完成侧边栏入口对齐。

## 兼容性与升级

本补丁只修改 Client UI 行为、CSS、测试、截图与 README 展示。Host 行为、可组合记忆内核、配置键、RPC 权限、公开工具 schema、持久化格式、Provider、凭据，以及已有 Runtime、Document 与 Memory Space 数据均不变。

无需数据迁移。更新 `dsh-mnemon` 后重启每个使用它的 DSH profile，再重新打开记忆系统界面即可。回滚到 `0.3.0` 不需要反向迁移。

## 验证

- 完整 TypeScript 与 Vitest 验证通过，共 473 项测试；本地非 Windows 环境只跳过一项 Windows 专用 smoke test。
- 可复现双构建验证 103 个生成文件哈希完全一致。
- 隔离的真实 Headless profile 成功激活，模型请求可见 35 个工具，其中包含 5 个代表性 Mnemon 工具。
- 发布包包含 110 个文件；10 个 Node 兼容公开入口均可成功导入，publint strict 与 attw ESM profile 全部通过。
- 发布提交通过 `git diff --check`。

可组合记忆架构与冻结的 Benchmark 记录见 [v0.3.0 发布说明](./v0.3.0.md)。
