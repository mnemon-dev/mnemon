# v0.5.21：大型 Native 记忆空间与更精简的热记忆

**简体中文** | [English](../../en/releases/v0.5.21.md)

本补丁版本包含 v0.5.20 之后合并的三个 PR：

- **大型 Native 空间恢复可用**（[#321](https://github.com/omdsh-dev/dsh-mnemon/pull/321)，issue [#320](https://github.com/omdsh-dev/dsh-mnemon/issues/320)）。
  - Mnemon Native 在三处读取整个记忆空间：内容列表、图谱，以及运行时记忆满容量归档前的逐字比对。此前每条 Mnemon 命令的输出上限都是 2 MiB，而约 1,000 条记忆的空间会返回 3–9 MB。
  - 在 900 条记忆的空间上，内容页显示 0 条记忆，图谱显示“连接不可用”；满容量时添加工作记忆会失败并提示安装 Mnemon，工作记忆因此无法腾出空间。
  - 现在这几次整库读取的上限为 128 MiB，其余命令仍为 2 MiB。失败时会写明原因：只有启动失败才提示安装 Mnemon。
- **空闲审查每轮只写一层**（[#322](https://github.com/omdsh-dev/dsh-mnemon/pull/322)，issue [#319](https://github.com/omdsh-dev/dsh-mnemon/issues/319)）。
  - 空闲审查是唯一无人值守的写入者，此前会把稳定的项目事实和决定写入每轮都会加载的 MEMORY.md，同一轮审查可能把同一知识同时写成项目档案和工作记忆。
  - 现在审查先考虑项目档案。MEMORY.md 只收用户明确说过、且项目档案和已有条目都未涵盖的简短规则，例如约定、纠正、环境事实或工具特性；设计、实现细节、路径、端口等项目记录不会进入。
  - 审查 guard 让每轮只写一层：建了项目档案后，修改工作记忆会被拒绝；修改工作记忆后，新建项目档案会被拒绝。USER.md 的修改不受影响。
  - 分层策略页面的**空闲审查**中新增**写入运行时记忆**开关（`idleReview.runtimeMemory`，默认开启），关闭后审查只创建项目档案。
- **兜底侧栏入口与 DSH 原生行一致**（[#323](https://github.com/omdsh-dev/dsh-mnemon/pull/323)，issue [#318](https://github.com/omdsh-dev/dsh-mnemon/issues/318)）。
  - 在没有 DSH 原生面板席位的布局中，Mnemon 会自行插入“记忆系统”入口，而它沿用了旧样式：与 DSH 的行并排时字更小、偏灰，并向右缩进 8px。
  - 现在它沿用 DSH 面板行的数值：继承的 14px 主要文字色、相同的内边距、外边距与圆角、16px 图标（折叠时 18px）以及 DSH 的高亮；打开时还会标记 `aria-current="page"`。有原生席位的布局不受影响。

## 升级与兼容性

支持的宿主：**DSH 0.2.0-rc.2**（npm `latest` 与 `next`）和 **DSH 0.1.7-rc.2**。完整 profile 需要 Node `^22.19.0 || >=24.0.0`。更早的宿主请继续使用 v0.5.16。

在**插件 → 添加插件**中安装 `dsh-mnemon@0.5.21`，然后选择**立即启用**。也可以使用命令行：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.21
```

发布后 24 小时内请带上版本号。pnpm 11 不会选用发布不足一天的版本，在此之前普通安装或更新会得到 0.5.20，两个宿主都接受它。带版本号安装会固定版本，之后可用 `dsh plugin --profile web update --latest dsh-mnemon` 升级。

- **已有安装：**发布后 24 小时内运行 `dsh plugin --profile web add dsh-mnemon@0.5.21`，之后 `dsh plugin --profile web update dsh-mnemon` 即可（带版本号安装的用 `update --latest`），然后重启 DSH。桌面版在应用的插件页中更新后完全退出并重新打开。
- **空闲审查：**已有 profile 在新规则下继续写入运行时记忆；关闭**写入运行时记忆**可让审查只写项目档案。本版本之前审查写入的 MEMORY.md 条目会保留，直到手动删除。
- **大型空间：**新上限需要新的记忆空间 Source 与 Mnemon Native 同时生效，Starter 已锁定两者；在旧版记忆空间宿主上，Mnemon Native 0.5.8 仍使用 2 MiB 上限。

无需迁移记忆数据或配置。
