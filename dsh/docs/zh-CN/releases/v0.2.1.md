# v0.2.1：运行时记忆中的字面花括号

**简体中文** | [English](../../en/releases/v0.2.1.md) | [能力地图](../guides/capabilities.md)

v0.2.1 是一次聚焦 system prompt 组装稳定性的补丁发布。运行时记忆现在可以包含精确字面文本 `{{}}`，不会再导致整轮运行失败。

## 修复

- `USER.md` 或 `MEMORY.md` 中的精确字面 `{{}}` 会原样保留在组装后的 `mnemon:runtime-memory` section 中；
- 同一段记忆里的合法 prompt 变量仍会正常插值；
- 其他 system prompt section 的变量和行为保持不变。

该修复只将空花括号字面量通过 Mnemon 专用 prompt 变量传递。宿主插值器不会再次扫描变量替换值，因此模型最终仍会看到原始 `{{}}` 文本，同时不会放宽真实 prompt 变量引用的严格校验。

## 文档

仓库首页更新为实时多记忆空间关系图快照，并更清晰地说明不同 Provider 的可观察范围。

## 升级

更新 dsh-mnemon 后重启对应 DSH profile 即可。本补丁不会迁移、改写或删除运行时记忆、项目档案、记忆空间或 Provider 数据。

当前次版本引入的完整三层记忆系统能力见 [v0.2.0 发布说明](./v0.2.0.md)。
