# v0.3.6：可靠的异步 Recall 与 Web 工作流

**简体中文** | [English](../../en/releases/v0.3.6.md) | [能力地图](../guides/capabilities.md)

v0.3.6 完成异步子 Agent Recall 生命周期修复，并汇总 v0.3.5 以来已合并的 Web 导航、CLI 发现、主题、Runtime Memory 和托管 embedding 改进。已发布 DSH 基线仍为 0.1.1-rc.2，同一插件同时验证仅提供源码的 0.1.2-alpha.1 预览版。

## 主要变化

- **稳定的异步 Recall。** 子任务保留创建时捕获的 View 和运行时授权，不受父任务结束、父任务后续回合、View 回收或设置切换影响。每个执行回合拥有自己的 Recall、Related 和 Documents 预算与缓存；回合内并发调用共享限制，兄弟任务和冷恢复 activation 不串用其他任务的证据或预算。缓存重放仍严格限制在请求的 Memory Space 子集中。[#130](https://github.com/omdsh-dev/dsh-mnemon/pull/130) 完成了 [#116](https://github.com/omdsh-dev/dsh-mnemon/pull/116) 的部分修复。
- **由插件自身持有 Runtime Memory 快照。** Mnemon 使用归属于插件自己的消息提供变化后的运行时快照，不再放入 Host 共用的 runtime-context 投影。记忆变化不再导致其他插件的稳定上下文片段被重复发送。[#107](https://github.com/omdsh-dev/dsh-mnemon/pull/107)
- **可靠的记忆系统导航与 CLI 检查。** Panel snapshot 方法在新版 DSH client 下保留正确的 store receiver；记忆系统与其他面板之间的切换以 Host 实际可见状态为准。配置为命令名的 CLI 会通过 PATH 解析，使状态检查和版本检查保持一致。[#113](https://github.com/omdsh-dev/dsh-mnemon/pull/113)、[#127](https://github.com/omdsh-dev/dsh-mnemon/pull/127)
- **一致的默认主题与弹窗。** 记忆系统画布遵循 Host 官方明暗背景；共用弹窗使用 layer-2 表面并提供画布底层，透明页脚避免半透明主题重复叠色。[#126](https://github.com/omdsh-dev/dsh-mnemon/pull/126)、[#129](https://github.com/omdsh-dev/dsh-mnemon/pull/129)
- **托管 embedding 凭据与协议选择。** Native embedding 设置支持可选 API key，以及 `auto`、`ollama` 或 `openai` 协议覆盖，包括没有 `/v1` 后缀的 OpenAI-compatible endpoint。关闭覆盖时不改变现有 Host 环境。[#117](https://github.com/omdsh-dev/dsh-mnemon/pull/117)
- **可复现验证。** alpha 任务在 pnpm 运行前检查期间保留显式源码链接；新增真实 DSH Agent loop 与 JSONL 冷恢复测试覆盖异步生命周期。发布包体积检查容纳新增 embedding 与委托回合实现，测试夹具仍不进入 npm 包。[#121](https://github.com/omdsh-dev/dsh-mnemon/pull/121)、[#130](https://github.com/omdsh-dev/dsh-mnemon/pull/130)

## 安全与升级

无需迁移 Runtime、Documents、Memory Space 或 Provider 数据。既有 embedding 配置继续有效，API key 与协议覆盖均为可选。保存的密钥属于 DSH 设置，不应复制到发布日志、截图或记忆内容。模型 Recall 缺少有效执行回合 pin 时会被拒绝，不再继承父任务的最新 View。

已经运行的子任务会保留原运行时，直到该 activation 销毁；停用旧数据位置前，应等待这些任务完成或取消它们。更新 `dsh-mnemon` 后，重启所有使用它的 DSH profile，并重新打开记忆系统。Registry 安装继续使用 DSH 0.1.1-rc.2；alpha 是源码验证目标，不是 npm 安装目标。

回滚到 0.3.5 不需要数据转换，但会恢复此前的 Recall 与 Web 行为，并失去本版 embedding 密钥和协议控制。依赖新覆盖项之前，请保留设置备份。

## 验证

- 本地 Node.js 24 完整验证通过 574 项测试，在 macOS 上仅跳过一项 Windows 专用测试。异步修复新增 29 项回归用例，包含真实 DSH Agent loop、工具流水线和 JSONL 冷恢复。
- CI 覆盖 Linux Node.js 22.19 与 24、Windows Node.js 24，以及精确源码链接的 `dsh-v0.1.2-alpha.1` tag。已合并实现在准备发布前通过全部四项任务。
- 可复现双构建验证 107 个生成文件；隔离的真实 Headless profile 暴露 35 个工具，其中包含 5 个代表性 Mnemon 工具。发布包内容检查、10 个 Node-compatible 公开入口导入、publint strict 与 attw ESM profile 全部通过。
- 保留既有真实 npm WebUI 的[导航与 CLI 前后对照](../../pr-assets/npm-sidebar-cli/README.md#简体中文)及[弹窗表面验证](../../pr-assets/dialog-surfaces/README.md)。这些记录标明了精确的发布前补丁构建，不会被重新标注为本版发布截图。
- 发布变更通过 `git diff --check`；不提交生成的 `lib/` 或测试专用数据。
