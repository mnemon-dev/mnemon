# v0.5.5：远程 RPC 路由与浅色素材

**简体中文** | [English](../../en/releases/v0.5.5.md)

v0.5.5 修复已认证的远程 WebUI 调用可能收到 HTTP 403 的问题，并更新文档中的记忆空间截图与录制。本版包含 [PR #197](https://github.com/omdsh-dev/dsh-mnemon/pull/197) 和 [PR #196](https://github.com/omdsh-dev/dsh-mnemon/pull/196)。

## 远程页面使用已认证网关

远程浏览器对状态、Source 目录、设置、View、激活和管理操作的调用，改为使用 DSH 命名空间 API Gateway。本地回环客户端继续使用既有 RPC 通道。检测也覆盖 `isLoopback` 表示 Host 归属、但页面实际来自远程 origin 的远程桌面连接。

DSH 继续负责 Host/Origin 检查和浏览器认证或配对。Mnemon 对网关写操作、ZIP 操作、View mutation 和设置修改，另行要求启动配置 `remoteAccess: trusted-host`。没有该授权时，设置仍可读取，但返回 `writable: false`；普通读取与小范围激活继续可用。原有 `writeEnabled` 限制仍然生效。参见[远程部署](../guides/operations.md#cloud-hosted-webui)与[配置说明](../reference/configuration.md#浏览器认证)。

网关映射使用正式发布的 Typert protocol peer 契约，复用既有处理器，保留取消信号并校验返回的 RPC envelope，不改变 Provider 契约或存储格式。

## 浅色截图与录制

[双语浅色图集](../../assets/webui-v0.5.4/README.md)包含 60 张原始 JPEG 和两段约 42 秒的连续演示。采集前先将 Mnemon Pack 安全导入临时隔离存储，覆盖记忆空间、检索、实体、图谱、弹窗、npm CLI 引导、子包展开、设置、备份预览与窄屏布局。

随包 README 与当前指南均改用此图集。截图保留真实的 **v0.5.4 采集版本**，不将其标为 v0.5.5 远程传输修复的证据。142 份历史媒体的原始哈希保持不变；来源 ZIP、数据库、凭据和原始日志不随仓库分发。

## 发布包与升级

本次仅将 **`dsh-mnemon` 升级到 `0.5.5`**。十六个官方插件继续使用 `0.5.4`，由 Starter 精确固定；未变化的插件包不重复发布。

```sh
dsh plugin --profile web add dsh-mnemon@0.5.5
```

重启 DSH 并刷新浏览器，让新 Client 与 Host 路由同时生效。Headless Profile 将 `web` 替换为 `headless`。Mnemon CLI 继续通过 npm 上的 `@mnemon-dev/mnemon` 单独安装与维护。

不需要迁移记忆数据；既有 ID、Provider 连接、配置格式与存储数据保持兼容。远程管理需要上述显式授权，早期 0.1.2 Host 文档将 `remoteAccess` 仅描述为回滚选项的说法不再适用于该网关路径。回滚时在同一 Profile 安装 `dsh-mnemon@0.5.4` 并重启 DSH，十六个固定子包版本本就一致。

## 验证与边界

已合并的 RPC 修复通过本地、已配对远程、管理拒绝与受信管理路径测试。其脱敏的真实配对 HTTPS 冒烟测试确认，状态、Source 目录和设置请求通过网关成功返回；精确环境见 #197。素材审计检查了全部 60 张截图和 333 个视频源画面，旧标签 OCR 匹配为零，两段 MP4 均可成功解码。

发布门禁覆盖版本化工作区、独立插件制品、完整混合版本 Starter 安装、冻结制品完整性、npm 回读以及从 v0.4.7 升级。传输和 UI 机制测试不代表模型质量或真实云 Provider 行为；窄屏与 Host 设置页的已知限制继续按图集中的范围记录。
