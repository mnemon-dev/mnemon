# v0.5.2：Starter 原子停用与独立发版

**简体中文** | [English](../../en/releases/v0.5.2.md)

v0.5.2 修复 [Issue #185](https://github.com/omdsh-dev/dsh-mnemon/issues/185) 报告的 v0.5 Starter 生命周期回归，同时完成 Source、Strategy 与 Provider 从统一版本转为独立版本发布的一次性迁移。

## 修复

既有的 `mnemon` Entry 继续作为公开配置目标，并重新成为完整 Starter 的生命周期总开关：

```yaml
- id: mnemon
  disabled: true
```

该覆盖项现在会同时停用 Core/Host、Runtime、Documents、Memory Spaces、默认三层 Strategy 和三个可选 Strategy 增强。下游四个 Entry 不再等待缺失的 `mnemonMemory`，因此 Mnemon 停用时 DSH Host 与 WebUI 仍可正常启动。

所有既有 Entry id 和配置目标保持有效。停用 Starter 不会卸载包、调用 Provider、迁移存储或删除记忆数据。删除该覆盖项，或把它改为 `false`，再重启 DSH，即可重新启用完整 Starter。[PR #186](https://github.com/omdsh-dev/dsh-mnemon/pull/186)。

## 独立包发布

本版本会把 `dsh-mnemon` 与十六个官方插件一次性全部发布为 `0.5.2`。这是因为独立版本迁移修改了每个包的已发布依赖元数据，所以首次切换需要全量发布。

从 v0.5.2 之后开始，只有自身发布制品发生变化的包才升级。`dsh-mnemon` 继续作为聚合 Starter 与经过完整验证的精确 BOM；任一固定插件版本变化时，Starter 也会升级。发布 workflow 会相对上一版本计算选择集，按依赖层有界并发发布选中的插件，完成 Registry 回读验证后最后发布 Starter。[PR #181](https://github.com/omdsh-dev/dsh-mnemon/pull/181)。

## 升级与兼容性

在所属 DSH profile 中安装精确稳定版并重启：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.2
```

Headless profile 将 `web` 改为 `headless`。v0.5.2 Starter 会精确固定经过验证的十六个 `0.5.2` 官方插件，普通用户不需要逐个安装；稳定 npm 通道仍是 `latest`。

本版本不迁移 RPC 权限、凭据、存储路径、记忆格式、Document 格式、Provider 数据或扩展契约，现有 v0.5.x profile 与数据可直接使用。与任何升级一样，请先停止写入并备份有效记忆根、工作区 Documents、DSH profile/配置和单独管理的 Provider 数据。

## 验证

报告中的故障已在 DSH 0.1.2-rc.1、Node.js 22.23.2 环境中，通过 profile 保留的 `disabled: true` 精确复现。修复前 Runtime、Documents、Memory Spaces 和默认 Strategy 都会持续等待 `mnemonMemory`；同一配置在只有单体 Entry 的 v0.4.7 中看起来不会影响启动。

修复后的构建通过完整 workspace 校验、全部包构建/类型检查/测试、确定性输出、公开入口与包内容检查、真实 DSH Headless 激活，以及隔离的 Linux Node.js 22.23.2 验证。一次性真实 WebUI profile 正常启动，并显示八个 Mnemon Entry 全部停用；浏览器没有错误，模型也没有收到任何 Mnemon 工具。实现 PR 保留了截图和精确回归夹具。

发布 workflow 还会冻结并验证选定制品，独立安装每个插件，编译外部 SDK 消费者，验证真实 Starter 组合，从 npm 回读全部包，并对从 v0.4.7 升级执行 Registry 冒烟测试。

## 回滚

在同一 profile 中重新安装 `dsh-mnemon@0.5.1` 并重启 DSH，无需转换数据。如果回滚后 profile 仍保留停用的 `id: mnemon`，v0.5.1 的 pending Entry 故障可能重新出现；启动旧 Host 前，应删除该覆盖项，或显式停用全部四个依赖的 Source/Strategy Entry。
