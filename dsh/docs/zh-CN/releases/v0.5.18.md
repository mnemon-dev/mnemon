# v0.5.18：安装后直接启用与桌面 CLI 静默运行

**简体中文** | [English](../../en/releases/v0.5.18.md)

本补丁版包含 v0.5.17 后合入的两项修复：

- **安装启用无需重启 DSH**（[#308](https://github.com/omdsh-dev/dsh-mnemon/pull/308)）：Desktop 与官方 WebUI 使用隔离依赖时，宿主启动时未选中的 bundle 也能正常加载默认 Source 和 Strategy。Mnemon 先准备依赖解析，再启动原生分组，并在自己的注入作用域中注册 Web RPC。官方 WebUI 安装后可直接点击“立即启用”。
- **Native CLI 静默运行**（[#306](https://github.com/omdsh-dev/dsh-mnemon/pull/306)、[#305](https://github.com/omdsh-dev/dsh-mnemon/issues/305)）：对经过验证的 Mnemon npm 安装，记忆操作与版本检查直接调用 Native 可执行文件，避免 npm 启动器在 Windows 上额外弹出控制台窗口。更新仍由 npm 管理，并继续兼容其他 CLI 安装方式。

## 升级与兼容

支持的宿主仍为 **DSH 0.1.7-rc.2**。完整 Profile 需要 Node `^22.19.0 || >=24.0.0`；包的 Node 入口导入下限仍为 20。旧宿主请继续使用 v0.5.16。

可在官方 WebUI 的“添加插件”中安装 `dsh-mnemon@0.5.18`，然后点击“立即启用”。也可使用 CLI：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.18
```

Headless Profile 将命令中的 `web` 替换为 `headless`。如果运行中的宿主已经加载旧版，请在升级后重启一次 DSH 并刷新浏览器，以加载新代码；新版首次安装和启用无需重启。更新或卸载已加载过的包，仍须遵循宿主正常的重启要求。

本版不需要迁移记忆存储。核心和组件开关保留现有行为与保存的选择。请保持新增的 Starter 就绪组件启用，使用 bundle 或核心开关控制整套组合。其他已加载插件保留其依赖路径，DSH 源码和共享 Connection 实例保持不变。

上游 `cordis:group` 显示与开关问题仍记录在[兼容性说明](../reference/compatibility.md#dsh-017-bundle-组件列表)中，不代表运行中的 Source 或 Strategy 已停止。
