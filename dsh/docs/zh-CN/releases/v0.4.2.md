# v0.4.2：共用 Builtin 入口与规范配置

**简体中文** | [English](../../en/releases/v0.4.2.md) | [配置参考](../reference/configuration.md)

v0.4.2 为 Sidebar 优先迭代的记忆工作台恢复可选会话入口，不恢复独立的旧版界面，也不包含计划中的 v0.5 view-based 架构。[#142](https://github.com/omdsh-dev/dsh-mnemon/pull/142)、[#139](https://github.com/omdsh-dev/dsh-mnemon/issues/139)

## 变更

- **同一个工作台，两种展示位置。** 默认仍为 Sidebar；设置中选择 Builtin 后，在会话标签页展示相同页面、弹窗和样式，保存后实时切换，两个入口不会同时挂载。
- **自动对应会话范围。** Builtin 隐藏范围标记、工作区选择和对齐控件。全局范围继续共享，工作区范围跟随所属会话 cwd，自定义范围使用 `dataDir`；读写与独立任务复用现有 Host 路由，全局 USER.md 例外保持不变。
- **规范拼写统一为 `builtin`。** 历史 `buildin` 仍可输入，但运行时和界面统一为 `builtin`，并通过 DSH 带修订号保护的设置接口写回。覆盖启动、外部配置热更新和旧客户端 RPC 写入，保留注释与其他字段；并发期间用户较新的 Sidebar 选择优先。
- **安全的生命周期。** `tabEnabled` 控制所选入口；对话快捷操作打开对应位置，切换会话清理旧数据和编辑器，不改变已存记忆。

## 升级与兼容性

在所属 DSH profile 中安装 `dsh-mnemon@0.4.2`，然后重启该 profile。如需在各会话内展示工作台：

```yaml
mnemon:
  displayMode: builtin
  storageScope: workspace
```

- **保留的旧偏好会重新生效。** v0.4.0–v0.4.1 忽略 `displayMode: buildin`，v0.4.2 会恢复该偏好并保存为 `builtin`。希望继续使用独立入口时请选择 Sidebar；未设置展示位置时仍默认 Sidebar。
- 仅存在于 profile 的旧值通过规范用户设置覆盖，不直接改写 profile 文件。只读设置仍识别旧拼写，但不绕过权限；落盘失败会记录日志，不关闭已归一化入口。
- Runtime、Documents、Memory Spaces、Pack 格式、存储路径、Provider 凭据与 RPC 权限保持不变。唯一自动迁移的是展示偏好，不是记忆数据；继续包含 v0.4.1 的修复。
- 已发布 DSH 0.1.1-rc.2 仍为依赖基线；DSH 0.1.2-alpha.1 继续作为仅提供源码的兼容性目标。

## 回滚

在同一 profile 中重新安装 `dsh-mnemon@0.4.1` 并重启；它会忽略 `displayMode` 并回到 Sidebar，无需转换数据。若回退到 v0.3.x，请先改用旧拼写 `buildin` 或 `sidebar`，这些版本不接受规范值 `builtin`。

- v0.4.2 发布候选通过完整 `pnpm run verify`：630 项测试通过，1 项 Windows 专用测试在 macOS 跳过；108 个构建文件确定性检查、35 个 Headless 工具及 5 个代表调用、115 文件发布包、10 个 Node 兼容入口、严格 publint 与 attw 检查均通过。
- 将实际 v0.4.2 tarball 安装到隔离的 DSH 0.1.1-rc.2 / Web-all 0.3.6 profile，并使用官方 Mnemon 0.2.5 CLI。启动后旧 `buildin` 自动保存为 `builtin`；界面显示 0.4.2，隐藏 Builtin 范围控件，实际读写根对应所属工作区。四个主页面、三个创建弹窗的打开与取消、中英文切换，以及从已安装 tarball 导入全部 10 个入口均通过。未提交记忆或组件更新；模型仅使用本地固定响应，未测试付费模型或远程 Provider。
- 实现 PR #142 在合并前通过 Linux Node.js 22.19/24、Windows Node.js 24 和源码链接 DSH 0.1.2-alpha.1 CI。
- [实现验证记录](../../pr-assets/builtin-139/README.md)包含未修改的 npm 0.4.1 对照版、真实 Mnemon 0.2.5 状态、三种存储范围、十轮页面往返及保持不变的记忆文件哈希；其中截图明确来自发布前本地构建，不冒充已发布的 0.4.2 包。
