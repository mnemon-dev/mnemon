# v0.5.15：USER 工具写入、Runtime 元数据与皮肤接口

**简体中文** | [English](../../en/releases/v0.5.15.md)

v0.5.15 包含以下改进：

- [#282](https://github.com/omdsh-dev/dsh-mnemon/pull/282) 修复 [#281](https://github.com/omdsh-dev/dsh-mnemon/issues/281)：`mnemon_runtime_memory` 在 `target=user` 时接受模型工具层附带的空占位参数 `branches: []`，恢复 USER 新增、替换和移除。非空 USER 分支仍被拒绝，MEMORY 的分支设置与清空行为保持不变。
- [#283](https://github.com/omdsh-dev/dsh-mnemon/pull/283) 解决 [#280](https://github.com/omdsh-dev/dsh-mnemon/issues/280)：Runtime 的模型上下文投影包含已存储的重要性，以及按天计算的创建、更新年龄。默认 Strategy 明确说明快照受上下文预算限制，缺少某条记录不代表它已被删除。
- [#284](https://github.com/omdsh-dev/dsh-mnemon/pull/284) 实现 [#273](https://github.com/omdsh-dev/dsh-mnemon/issues/273)：Sidebar 与 Builtin 提供稳定的 Mnemon 根选择器，支持覆盖 `--mn-bg`、`--mn-backdrop` 和 `--mn-surface`。[皮肤开发手册](../development/skin-integration.md)包含 dsh-web 接入、旧类名迁移与验证步骤。

## 包版本与升级

| 包 | 原版本 | 新版本 |
|---|---|---|
| `dsh-mnemon` | 0.5.14 | **0.5.15** |
| `dsh-mnemon-source-runtime` | 0.5.8 | **0.5.9** |
| `dsh-mnemon-strategy-default-three-tier` | 0.5.5 | **0.5.6** |

其余十四个配套包版本不变，Starter 精确固定完整组合。Mnemon CLI 独立维护，相关修复的本地验证使用官方 CLI 0.2.9。

备份 DSH Profile 配置及相关 Mnemon 数据，然后升级：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.15
```

重启 DSH 并刷新浏览器。Headless Profile 将命令中的 `web` 换为 `headless`。Client 下限仍为 DSH 0.1.5-rc.1，完整 DSH Profile 要求 Node `^22.19.0 || >=24.0.0`。

## 兼容性与数据

Runtime 的原始正文、JSON/Markdown 存储格式、精确匹配和容量计算保持不变；新增元数据由 Source 在编译模型投影时生成，不需要数据迁移。每个回合仍使用固定快照，Scoped、Light Context 与 Auto Capture 可继续组合使用。

官方主题保留默认不透明背景。现有皮肤需要显式使用公开选择器与变量，才能自定义 Mnemon 背景；安装皮肤不会自动启用玻璃效果。挂载到 `body` 的弹窗保持独立样式，皮肤适配不改变 Provider 或数据权限。
