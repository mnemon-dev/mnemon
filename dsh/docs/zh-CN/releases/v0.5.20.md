# v0.5.20：不再有单独的 Starter 开关

**简体中文** | [English](../../en/releases/v0.5.20.md)

本补丁版包含 v0.5.19 后合入的三个 PR：

- **Starter 的就绪步骤并入组件组**（[#314](https://github.com/omdsh-dev/dsh-mnemon/pull/314)）：0.5.18 与 0.5.19 在插件页单独列出一行就绪条目 `dsh-mnemon/starter`，组件组要等它就绪。关闭这一行（例如为了消除更新后的一条报错）会让全部组件一直等待 `mnemonStarterReady`：`dsh web` 启动后没有记忆系统，桌面版则按启动失败处理并提议移除插件。组件组 `mnemon-bundle` 现在使用模块 `dsh-mnemon/bundle`，由它自己准备 Starter 的依赖解析，再用 DSH 自己的 `cordis:group` 挂载各组件。“立即启用”仍然无需重启，那一行已经去掉，处于卡住状态的 profile 更新并重启后即可恢复。
- **更新后的恢复说明**（[#313](https://github.com/omdsh-dev/dsh-mnemon/pull/313)、[#315](https://github.com/omdsh-dev/dsh-mnemon/pull/315)）：[安装与启动](../guides/installation.md#常见问题)补充了更新后不重启出现的 `ERR_PACKAGE_PATH_NOT_EXPORTED`、`waiting for service: mnemonStarterReady` 与桌面版的插件恢复页，并说明 pnpm 的一天期限可能退回不止一个版本。

## 升级与兼容

支持的宿主不变：**DSH 0.1.7-rc.2**（npm `latest`）与 **DSH 0.2.0-rc.1**（npm `next`）。完整 Profile 需要 Node `^22.19.0 || >=24.0.0`。旧宿主请继续使用 v0.5.16。

在**插件 → 添加插件**中安装 `dsh-mnemon@0.5.20`，然后点击**立即启用**。也可使用 CLI：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.20
```

发布后的 24 小时内请带上版本号。pnpm 11 不会选用发布不足一天的版本；由于 0.5.18 与 0.5.19 都在 2026-09-28 发布，在北京时间 2026-09-30 01:31（UTC 09-29 17:31）之前它会退回 0.5.17，而 DSH 0.2 会拒绝这个版本。带版本号安装会固定版本，之后用 `dsh plugin --profile web update --latest dsh-mnemon` 升级。

- **已有安装：** 发布后的 24 小时内运行 `dsh plugin --profile web add dsh-mnemon@0.5.20`，因为在此之前 pnpm 11 的 `update` 与 `update --latest` 都会停留在已安装的版本；之后运行 `dsh plugin --profile web update dsh-mnemon`（带版本号安装的用 `update --latest`）即可。然后重启 DSH。桌面版在应用的插件页中更新，然后完全退出并重新打开应用。在重启之前，从 0.5.18 或 0.5.19 更新后会提示 `mnemon-bundle (dsh-mnemon/bundle): pending (waiting for service: mnemonStarterReady)`，因为正在运行的加载器仍保留旧的组件组。
- profile patch 中残留的 `- id: mnemon-starter` 不再对应任何条目，会被忽略。桌面版日志会提示 `patch: entry "mnemon-starter" not found`，可以删除这两行。`dsh-mnemon/starter` 仍然导出，供仍插入它的组合使用。
- 插件页中的容器行显示为 `dsh-mnemon/bundle`，不再是 `cordis:group`，并与以前一样显示为已关闭（[上游 #649](https://github.com/dsh-external/issues/issues/649)）。
- DSH 的配置 schema 导出（`dsh web --dump-config-schema`）只遍历原生 group，现在会把 `mnemon-bundle` 报告为无法识别的树载体，并略去 Mnemon 各组件的 schema，与 DSH 自带的 agent preset 相同。运行时配置与 profile patch 不受影响。

本版不需要迁移记忆存储或配置。
