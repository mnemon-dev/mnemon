# v0.5.3：更清晰的版本维护

**简体中文** | [English](../../en/releases/v0.5.3.md)

v0.5.3 改进状态页版本维护，明确 Host 执行与 Source 展示的归属，并更新官方包内的文档。包含 [PR #190](https://github.com/omdsh-dev/dsh-mnemon/pull/190)、[PR #191](https://github.com/omdsh-dev/dsh-mnemon/pull/191) 和 [PR #192](https://github.com/omdsh-dev/dsh-mnemon/pull/192)。

## 版本维护

- 版本弹窗区分未安装、版本不可读、可更新、已是最新版、本地版本较新和等待重启等状态。Registry 查询失败时，仍可查看本地安装指引。
- Mnemon CLI 安装与迁移引导使用官方 npm 包 `@mnemon-dev/mnemon`。Host 确认活动 launcher 属于当前 npm 安装后，可更新由 npm 管理的 CLI；继续支持 Homebrew 和 Go 更新。
- Native 执行与版本检查共享 Memory Spaces 包的公开 CLI 发现入口。经过验证的 Windows npm launcher 通过 Node 执行，不调用任意 shell 脚本。
- dsh-mnemon 子包默认折叠，展开后可查看 Source、Strategy、Provider 版本、Starter 固定版本与所属 Profile。独立安装的包可在该 Profile 中更新；Starter 依赖随 Starter 更新，源码链接保持不变。
- 更新遵循管理权限和只读配置，拒绝并发写入，核验实际安装版本，并持续提醒重启，直到 Host 重新启动。

## 归属与文档

Host 回合与维护操作共享明确的执行归属和清理流程，覆盖后台向前台交接，并保留公开执行辅助逻辑的 Node 20 兼容性。Source 包自行维护默认页面文案和布局资产；Memory Spaces 配置与可选 Strategy 校验使用各自归属的公开辅助函数，保留既有默认行为。

紧凑工作台标题不再与较长的翻译文案重叠。已发布 README 与双语文档进一步说明可组合记忆边界、安装方式、独立包与数据范围，包含真实 DSH 截图和已验证的导航链接。

## 包版本与升级

本次 Starter 与十六个官方插件均升级到 `0.5.3`，因为各包的发布内容均有变化，包括 README。包仍采用独立版本；后续不会仅因 Starter 升级而重新发布未变化的包。

在所属 DSH Profile 中安装精确版本并重启：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.3
```

Headless Profile 将 `web` 改为 `headless`。Starter 通过 npm `latest` 通道安装经过验证的精确插件组合。Mnemon CLI 单独在 Host 所在机器的终端中安装或迁移，要求 Node.js 22 或更高版本：

```sh
npm install --global @mnemon-dev/mnemon@latest
mnemon --version
```

如果仍命中旧 CLI，先检查 `PATH`、`MNEMON_CLI_PATH` 与配置中的 `cliPath`，再重启 DSH。参见[快速开始](../guides/getting-started.md)和[运维指南](../guides/operations.md)。

## 兼容性、验证与回滚

既有 Entry id、配置、存储路径、记忆格式与 Provider 数据继续有效，无需数据迁移。升级前按运维指南备份有效记忆根、工作区 Documents、DSH Profile/配置和单独管理的 Provider 数据。

实现已通过 783 个根测试、workspace 验证、确定性构建、真实隔离 DSH Headless 激活，以及十六个插件独立仓库和十七个打包制品验证。[状态页证据](../../pr-assets/status-version-maintenance/README.md)记录了真实桌面和移动端版本弹窗检查。Windows launcher 使用模拟文件系统和进程夹具覆盖；显式启用的真实 Native 与 Windows 二进制测试需要各自环境。本次不消除[已记录的窄屏设置页限制](../reference/compatibility.md)。

发布 workflow 会验证并冻结版本制品，先发布插件依赖层、后发布 Starter，从 npm 安装完整组合，并在创建 GitHub Release 前对从 v0.4.7 升级执行 Registry 冒烟测试。

回滚时，在同一 Profile 中安装 `dsh-mnemon@0.5.2` 并重启 DSH，无需转换数据。若单独更新过 Profile 中独立维护的包或 CLI，需要分别恢复它们。

上一版：[v0.5.2](./v0.5.2.md)。
