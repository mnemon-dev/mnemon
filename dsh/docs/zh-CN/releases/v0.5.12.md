# v0.5.12：兼容 DSH RC 与 Alpha

**简体中文** | [English](../../en/releases/v0.5.12.md)

v0.5.12 包含 [#263](https://github.com/omdsh-dev/dsh-mnemon/pull/263)，修复 [#261](https://github.com/omdsh-dev/dsh-mnemon/issues/261)。回合记忆条使用 DSH 0.1.6-alpha.2 的 list 插槽要求的稳定 ID，同时保留 0.1.5-rc.2 的 chain selector；仅在回合完成后读取、展示记忆活动。注册成功后，“存入记忆”入口也能正常挂载。

Sidebar 与设置页改用 DSH 公开的默认／主会话 binding。Builtin 与 Better Sidebar 保留显式所属会话，包括无会话状态，避免切换工作区时借用其他会话的记忆范围。

## 发布包与升级

本次仅新发布 **`dsh-mnemon` 0.5.12**。十六个配套插件及其在 Starter 中的精确版本固定均不变。无需迁移配置或已有记忆；Mnemon CLI 继续独立维护。

Client 的兼容下限调整为 **DSH 0.1.5-rc.1**。Root 的两个框架 peer 均声明 `^0.1.5-rc.1 || ^0.1.6-alpha.2`，已明确验证 0.1.5-rc.2 和 0.1.6-alpha.2。缺少公开 UI Session 服务的旧版 DSH 应继续使用此前验证过的 Mnemon 版本。

```sh
dsh plugin --profile web add dsh-mnemon@0.5.12
```

重启 DSH 并刷新浏览器；Headless Profile 将命令中的 `web` 替换为 `headless`。完整 DSH Profile 需要 Node `^22.19.0 || >=24.0.0`。

## 验证

两套 DSH 版本均通过完整生产公开类型检查、正常 npm 制品安装、真实 WebUI 工具调用、Sidebar/Builtin 跳转、记忆条开关与页面重载。alpha 额外验证了两个独立插槽贡献同时存在，以及切换工作区后的记忆隔离。制品 Headless 检查涵盖十七个 Mnemon 工具、真实 Runtime 写入与状态、新进程持久化，以及禁用 Root 后工具数归零。

实现通过 1,183 项根包测试，5 项 opt-in 真实 Flash 测试跳过，并完成真实 Mnemon Native CLI 0.2.8 集成及十六插件／十七制品组合与升级验证。此次 macOS 验证跳过真实 OpenViking 和 Windows 专用检查。[双语证据报告](../../pr-assets/issue-261-dsh-slots/README.zh-CN.md)保留原始前后截图、制品完整性与复现脚本。模型响应来自明确的本地 OpenAI/Anthropic 夹具，不代表真实模型质量评测。

发布流程再次验证版本化制品，安装完整 Registry 固定组合，发布 Starter，并检查从 v0.4.7 开始的真实升级，通过后才创建 GitHub Release。
