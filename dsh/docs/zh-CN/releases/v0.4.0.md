# v0.4.0：Sidebar 唯一入口的记忆系统

**简体中文** | [English](../../en/releases/v0.4.0.md) | [能力地图](../guides/capabilities.md)

v0.4.0 将 Sidebar 设为记忆系统的唯一工作台入口，移除 builtin 展示模式和展示形态配置，保留 v0.3 架构与记忆数据格式。完整的 view-based 升级独立计划于 v0.5 发布，不包含在本版中。

## 主要变化

- **唯一工作台入口。** 记忆系统只从 DSH 左侧栏打开，不再注册 `conversation.view` 内嵌标签页；保留既有 Sidebar 页面、导航、弹窗与工作区选择。[#128](https://github.com/omdsh-dev/dsh-mnemon/pull/128)
- **移除展示形态选择。** 删除展示模式配置、中英文文案，以及 builtin 专用的外观、导航、内联编辑和样式分支，统一使用精简的 Sidebar 展示。
- **保留独立的实时显示开关。** `tabEnabled=false` 实时隐藏 Sidebar 入口和工作台，重新开启后恢复 Sidebar。Host RPC、命令和 Agent 工具始终保持注册；对话内的本回合记忆和存入记忆仍由 `mnemon-ui` 独立控制。
- **保留 v0.3.6 修复。** 异步 Recall 委托、回合独立预算、Runtime Memory 快照归属、面板导航、CLI 发现与 Host 主题弹窗修复继续有效。本版不引入新的 view-based 核心、SDK 或独立插件架构。

## 升级与兼容性

这是明确的展示行为与配置兼容性变化，不是数据格式迁移。

1. **builtin 用户切换到 Sidebar。** 旧配置值的实际拼写为 `buildin`。包含 `displayMode` 的既有 YAML 和用户设置仍可加载，包括该旧值；字段会被忽略，工作台统一使用 Sidebar。无需手工清理，也不会自动重写已有配置文件。
2. **调整类型集成和设置写入方。** `Config.displayMode` 与 `ResolvedConfig.displayMode` 已移除。新的设置 RPC 更新若包含 `displayMode`，会被拒绝；请从配置对象和更新请求中移除该字段，不要将旧配置的读取兼容理解为继续支持写入。
3. **保留记忆数据。** Runtime、Documents、Memory Space registry、Provider 数据、存储路径、凭据与权限边界保持不变，不迁移或删除记忆数据。
4. **显式选择次版本升级。** 在所属 DSH profile 中安装 `dsh-mnemon@0.4.0`，重启使用它的 profile，再重新打开记忆系统。限制为 `^0.3.x` 的依赖不会自动选择 v0.4.0。升级前请备份设置和数据。

已发布 DSH 基线仍为 0.1.1-rc.2；DSH 0.1.2-alpha.1 继续作为仅提供源码的兼容性验证目标，不是 npm 安装目标。

## 回滚

在同一 profile 中重新安装 `dsh-mnemon@0.3.6` 并重启，无需转换数据。如果保留了 `displayMode: buildin`，该偏好在旧版上会重新生效；若不希望恢复 builtin，请在旧版中删除该字段或选择 Sidebar。

## 验证

- 本地 macOS / Node.js 25.1.0 的完整 `pnpm run verify` 通过 582 项测试，仅跳过一项 Windows 专用测试。可复现双构建匹配 107 个生成文件；隔离的真实 Headless 激活暴露 35 个工具，其中包含 5 个代表性 Mnemon 工具。发布包内容检查覆盖 114 个文件，10 个 Node-compatible 公开入口导入、publint strict 和 attw ESM profile 全部通过。
- Sidebar-only 回归覆盖旧 `buildin` / `sidebar` 配置、展示形态选择器消失、实时显示开关，以及拒绝新的 `displayMode` 写入。
- 将 v0.4.0 tarball 安装到隔离的真实 DSH Web profile，并保留旧 `displayMode: buildin`：Sidebar 打开、返回与重开，无展示选择器的设置页、Runtime 弹窗，以及 680px 布局和 Escape 关闭均通过，浏览器控制台无错误。该 UI 专用夹具使用合成数据，并刻意让原生 CLI 不可用；不宣称完成真实 Mnemon CLI 或真实模型端到端验证。
- 已合并实现在准备发布前通过 Linux Node.js 22.19 与 24、Windows Node.js 24，以及源码链接 DSH 0.1.2-alpha.1 的 CI。
- [Sidebar-only 设置截图](https://raw.githubusercontent.com/omdsh-dev/dsh-mnemon/2296898ddde876aa49a5dd68165d6c40c069fcd1/docs/assets/screenshots/settings-sidebar-only.png)是实现 PR 的发布前证据，不会重新标注为 npm 发布版截图；既有 Web 导航与弹窗证据继续保留原版本标记。
