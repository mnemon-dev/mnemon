# v0.5.19：支持 DSH 0.2、桌面版管理记忆与新手安装指引

**简体中文** | [English](../../en/releases/v0.5.19.md)

本补丁版包含 v0.5.18 后合入的两个 PR：

- **支持 DSH 0.2.0-rc.1**（[#311](https://github.com/omdsh-dev/dsh-mnemon/pull/311)）：DSH 在安装插件前以及每次启动 profile 时，都会检查所有 `@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-*` peer 范围；此前的版本只声明支持 DSH 0.1.7，因此被 DSH 0.2 拒绝。Starter 与记忆空间 Source 现在接受 `^0.1.7-rc.2 || ^0.2.0-rc.1`，并由测试对两个运行时执行 DSH 自己的检查。
- **在 DSH 桌面版中管理记忆**（[#310](https://github.com/omdsh-dev/dsh-mnemon/issues/310)、[#311](https://github.com/omdsh-dev/dsh-mnemon/pull/311)）：桌面版窗口从应用自己的 `dsh-app://app/` 地址加载，Mnemon 曾把它当作远程页面，在默认的 `remoteAccess: read-only` 下，记忆系统与插件设置只读，而 Agent 工具仍可写入。应用窗口现在使用 Mnemon 的本地通道。从其他设备打开的页面保持默认只读，并会写明需要的授权与重启。
- **全新安装后的状态页**（[#311](https://github.com/omdsh-dev/dsh-mnemon/pull/311)）：Mnemon Native 会写出 CLI 版本，不再一直显示等待版本信息。
- **记忆交互保持一致**（[#307](https://github.com/omdsh-dev/dsh-mnemon/pull/307)）：回合记忆栏与“存入记忆”使用记忆系统的脑形标识；回合记忆栏写出每个工具做了什么，点击条目即在所在位置打开。对话与记忆空间页的“存入记忆”是同一个对话框，带任务 Agent 就绪标签，回执使用候选内容的语言。Mnemon 使用 DSH 的输入框、选择器与对话框按钮，对话框位于 DSH 的弹窗层级。工作区刷新会重新加载当前页面，状态页列出正在运行的 Provider，Native Provider 统一称为 Mnemon Native。
- **文档**（[#307](https://github.com/omdsh-dev/dsh-mnemon/pull/307)、[#311](https://github.com/omdsh-dev/dsh-mnemon/pull/311)）：新增[安装与启动](../guides/installation.md)，从一台空白电脑开始，经网页、桌面版或命令行一直走到第一条记忆；README 与各指南展示由真实模型录制的交互。

## 升级与兼容

支持的宿主为 **DSH 0.1.7-rc.2**（npm `latest`）与 **DSH 0.2.0-rc.1**（npm `next`）。完整 Profile 需要 Node `^22.19.0 || >=24.0.0`；包的 Node 入口导入下限仍为 20。旧宿主请继续使用 v0.5.16。

在**插件 → 添加插件**中安装 `dsh-mnemon@0.5.19`，然后点击**立即启用**。也可使用 CLI：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.19
```

Headless Profile 将命令中的 `web` 替换为 `headless`。发布后的 24 小时内请带上版本号：pnpm 11 不会选用发布不足一天的版本，会改装上一个版本，而 DSH 0.2 会拒绝它。24 小时后直接输入 `dsh-mnemon` 即可安装 0.5.19。带版本号安装会固定版本，之后用 `dsh plugin --profile web update --latest dsh-mnemon` 升级。详见[安装与启动](../guides/installation.md#常见问题)。

- **升级到 DSH 0.2：** 先更新 dsh-mnemon，再升级 DSH。若 DSH 0.2 启动时遇到旧版本，会将其停用；记忆数据不受影响，更新后即可恢复。
- **桌面版：** 在应用的插件页中更新。无需修改 `remoteAccess`；仅为绕过 #310 而添加的 `remoteAccess: trusted-host` 可以删除。
- 如果运行中的宿主已经加载旧版，请重启一次 DSH 并刷新浏览器。全新安装与“立即启用”无需重启。

本版不需要迁移记忆存储或配置。插件作者请注意：`dsh-mnemon/client` 的 Source 页面 SDK 新增 `SearchField`、`SelectField`、`WriteReceipt`、`TaskAgentTag` 与 `MemorySourcePageProps.refreshKey`，使用它们的三个官方 Source 现在要求 `dsh-mnemon ^0.5.19`。
