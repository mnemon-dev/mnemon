# v0.5.16：中文元数据、原生 Sidebar 与 Source 滚动

**简体中文** | [English](../../en/releases/v0.5.16.md)

v0.5.16 包含三项界面与制品修复：

- [#286](https://github.com/omdsh-dev/dsh-mnemon/pull/286) 为 DSH 中的主插件增加中文名称与描述，并保留英文 manifest 回退。打包制品会检查 locale 资源，仅修改 locale 的变更也纳入发布校验。原贡献者提交 [`d16d017`](https://github.com/omdsh-dev/dsh-mnemon/commit/d16d017aa5bb0c3bbbdb40dc5a95554266b6522a) 原样保留，校验与发布维护通过后续提交补充。
- [#287](https://github.com/omdsh-dev/dsh-mnemon/pull/287) 将记忆系统接入 DSH 原生 Sidebar 与主面板。切换到 Plugins 后显示所选页面，返回时保留 Source 状态。原生行样式、折叠导航和标题可见性已覆盖受测的官方外观与 Maid Atelier 皮肤，继续支持 Better Sidebar 和替换布局的回退路径。
- [#288](https://github.com/omdsh-dev/dsh-mnemon/pull/288) 让运行时、档案和记忆空间的边距与滚动容器对齐状态页。记忆空间滚动时保留标题与 Tab，切换 Tab 只重置所属 canvas；打开关联记忆时，将关联标题与关闭按钮定位到固定头部下方。

## 包版本与升级

| 包 | 原版本 | 新版本 |
|---|---|---|
| `dsh-mnemon` | 0.5.15 | **0.5.16** |
| `dsh-mnemon-source-memory-spaces` | 0.5.9 | **0.5.10** |

其余十五个配套插件版本不变。完整修复需要同时升级 Root 与 Memory Spaces Source，Starter 已精确固定全部十七个包的组合。Mnemon CLI 继续独立维护。

备份 DSH Profile 配置及相关 Mnemon 数据，然后升级：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.16
```

重启 DSH 并刷新浏览器。Headless Profile 将命令中的 `web` 换为 `headless`。Client 下限仍为 DSH 0.1.5-rc.1，完整 Profile 要求 Node `^22.19.0 || >=24.0.0`。

## 兼容性与数据

无需持久化迁移，已存记忆、存储格式和 Provider 权限保持不变。Source 的 `onResetScroll` 与 `onRevealElement` 回调均为可选，兼容旧 Host；旧 Host 需要手动滚动。现有 Root peer 最低版本不变。

正式 DSH 0.1.7-rc.2 仍可能在子组件运行时将 `cordis:group` 容器显示为 Off，其界面开关会返回 `unknown-plugin`。本版不修改 DSH，也不安装替代插件管理服务的适配器。本地上游候选补丁仅作为排查证据保留，不随 Mnemon 运行。
