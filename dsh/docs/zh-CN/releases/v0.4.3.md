# v0.4.3：折叠侧栏图标对齐

**简体中文** | [English](../../en/releases/v0.4.3.md)

v0.4.3 修复记忆系统折叠后的侧栏图标，并保持原有展开样式。[Issue #141](https://github.com/omdsh-dev/dsh-mnemon/issues/141)、[PR #144](https://github.com/omdsh-dev/dsh-mnemon/pull/144)。

## 修复

- 原生 DSH 正确应用折叠入口的居中与隐藏文字规则，不再依赖第三方 Web UI 的 frame 属性。
- 折叠图标使用与相邻控件一致的 primary label 颜色；SVG 画布调整为 20px，补偿图案内部留白，使可见尺寸协调。
- 展开时保留原有 18px SVG、间距、文字和 secondary 颜色，兼容 Web UI 0.3.9。修复只修改一个 CSS 文件，没有新增 JavaScript 或状态。

## 升级与兼容性

在所属 DSH profile 中安装 `dsh-mnemon@0.4.3`，然后重启。Sidebar 与可选 Builtin 入口保持 [v0.4.2 的行为与兼容规则](./v0.4.2.md#升级与兼容性)。

没有新增配置或迁移。记忆数据、存储路径、Pack 格式、Provider 凭据、RPC 权限和依赖均不变。DSH 0.1.1-rc.2 仍为 registry 基线；DSH 0.1.2-alpha.1 继续作为源码兼容性目标。

## 验证

- 发布候选通过完整 `pnpm run verify`：630 项测试通过，1 项 Windows 专用测试在 macOS 跳过；108 个构建文件确定性检查、35 个 Headless 工具及 5 个代表调用、全部 10 个 Node 兼容入口、publint 与 attw 均通过。
- 将实际 115 文件 tarball 安装到隔离的 DSH 0.1.1-rc.2 原生与 Web UI 0.3.9 profile，使用官方 Mnemon 0.2.6 CLI。版本 0.4.3、中英文四个主页面、原生浅色与深色图标、折叠居中及 20px SVG、展开时保留 18px SVG，以及从两个安装包导入全部 10 个入口均通过。未观察到浏览器控制台错误；既有依赖 source-map 和 Web UI `session/list` 警告仍存在。验证使用合成数据与本地模型桩，没有访问个人记忆或调用付费模型。

[实现验证记录](../../pr-assets/sidebar-icon/README.md)覆盖原生浅色与深色主题、Web UI 0.3.9、折叠与展开、页面导航及图标几何测量。截图和原始测量数据不进入 npm 包，既有包内容校验会检查发布文件白名单。

## 回滚

在同一 profile 中重新安装 `dsh-mnemon@0.4.2` 并重启，无需转换数据；折叠图标会恢复此前的外观。
