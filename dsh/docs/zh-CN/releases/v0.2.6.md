# v0.2.6：远端安全的 UI 可靠性

**简体中文** | [English](../../en/releases/v0.2.6.md) | [能力地图](../guides/capabilities.md)

v0.2.6 提升记忆系统在受信任远端部署、慢 Provider 以及快速切换工作区或页面时的读取与异步交互可靠性。

## 修复

- 单独刷新记忆空间卡片改用受信任读 RPC；远端只读部署不再出现“整体同步成功、卡片更新却 `Failed to fetch`”。
- HTTP Provider 会立即响应请求建立前已经取消的 signal；OpenViking 的回退延时也会使用规范错误拒绝。
- Provider 设置、档案阅读器、关联记忆遍历和实体视图会忽略旧作用域或旧交互的响应，不再覆盖最新 UI 状态。
- 环境不支持 `scrollIntoView` 时，关联记忆滚动会安全降级。

## 部署边界

- 浏览器代码保持传输中立：RPC 与部署 URL 均交给 DSH 宿主 connection，不自行拼接根相对 API、插件或静态资源路径。
- 完整的 `/prefix/` 托管仍需 DSH 为外壳、静态资源、插件包、RPC/API 和 WebSocket 提供统一 base URL；宿主级兼容工作已记录在 Roadmap。

## Roadmap

- 新增 Cordis / DSH 服务注入、热重载与 dispose、延迟注册 structured-output 工具和 `toolFilter` 隔离的契约测试方向。
- 新增显式宿主能力声明与真实 URL 子路径部署矩阵；本版本不会通过放宽子 Agent 工具隔离规避问题。

## 验证

- 完整测试套件 330 项通过；Windows 专用 smoke test 只会在非 Windows 本地环境跳过。
- 确定性构建、Headless 激活、包检查以及 Ubuntu、Windows CI 均通过。
- 真实 WebUI 覆盖记忆系统状态页、记忆空间概览与卡片刷新、快速页面切换和快速实体选择，浏览器无错误或警告。

## 升级

更新 dsh-mnemon 后重启对应 DSH profile。存储布局、schema、Provider 配置和工具契约均未改变，无需迁移数据。

上一个补丁版本见 [v0.2.5 发布说明](./v0.2.5.md)。
